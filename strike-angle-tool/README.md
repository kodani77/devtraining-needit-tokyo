# ショット角度ボード

ひっぱりアクションゲーム（モンスト等）で「どの角度で打てば何に何回当たるか」を事前に確認するためのツールです。
ブラウザで `index.html` を開くだけで動きます（ビルド・サーバー不要）。

## できること

| 機能 | 内容 |
| --- | --- |
| 角度表示 | 0° = 真上・時計回りの角度と「◯時方向」を表示。ボールの周りに分度器を描画 |
| 軌道シミュレーション | 壁・ブロック・敵での反射を追いかけ、反射点に番号を付けて表示 |
| 反射 / 貫通 | 反射タイプは敵で跳ね返る。貫通タイプは敵をすり抜けてヒット数だけ数える |
| 当たり判定 | ボス・雑魚・弱点・ブロック・壁ごとのヒット数、最初に当たる敵、雑魚の撃破数 |
| おすすめ角度 | 全方向を 0.5° 刻みで試し、指のブレ（±°）を考慮して安定して点が取れる角度を上位 5 つ表示 |
| 角度マップ | ボールの周りに「当たりやすい方向」を色の濃さで表示 |
| スクショ背景 | プレイ画面のスクショを背景に敷き、上下左右をトリミングしてフィールドに合わせる |
| ひっぱり操作 | ゲームと同じく「引いた方向の反対」に飛ばす操作モード |

## 当たり判定のモデル

```
ボール        半径 r の円
ボス / 雑魚   半径 R の円。ボールの中心が「R + r」の円に入った時点で接触（点線で表示）
弱点          敵に付く小さな円。ボールの体が触れた瞬間に 1 回（押し付けたままでは数えない）
ブロック      長方形。角は丸め（ミンコフスキー和）で判定するので、角に当たると斜めに弾かれる
              反射・貫通どちらのタイプでも跳ね返る
壁            フィールド外枠。四隅にぴったり入ると来た方向へ戻る
雑魚の撃破    「撃破まで◯回」に達するとその場で消え、以降は判定なし（0 回 = 倒れない）
移動距離      フィールド縦の何本分進むかで近似（スピード・摩擦の代わり）
```

おすすめ角度の評価点は「狙い」で重みが変わります。

| 狙い | ボス本体 | 雑魚 | 弱点 | 雑魚撃破 |
| --- | --- | --- | --- | --- |
| バランス | 3 | 1 | 4 | 2 |
| ボス集中 | 5 | 0.2 | 3 | 0 |
| 弱点狙い | 1 | 0.2 | 8 | 0 |
| 雑魚処理 | 0.5 | 2 | 0.5 | 6 |

各角度の点を ±ブレ幅で平均し（最低点も 2 割混ぜる）、少しずれても崩れない角度を上に出します。

## 使い方

1. 「画像を選ぶ」でプレイ画面のスクショを読み込み、トリミングでフィールド部分だけにする
2. 「＋ボス」「＋雑魚」「＋ブロック」で判定を置き、スクショの敵に重ねる（ドラッグで移動、選択して大きさ・撃破回数を調整）
3. ボスを選んで「＋弱点」で弱点を付ける
4. 「反射 / 貫通」と移動距離を自分のキャラに合わせる
5. フィールドの空いている所をドラッグして角度を決めるか、「おすすめ角度」を押す

キーボード: `←` `→` で 0.5°、`Shift` 併用で 5°、`Delete` で選択中の物を削除。

## ファイル構成

```
strike-angle-tool/
├── index.html          画面
├── css/style.css       スタイル（ライト / ダーク対応）
├── js/physics.js       物理・当たり判定エンジン（UI 非依存、Node からも使える）
├── js/app.js           キャンバス描画と操作
└── test/physics.test.js
```

テスト: `node --test strike-angle-tool/test/*.test.js`

## 限界

- 実際のゲームの速度減衰・友情コンボ・ギミック（ダメージウォール、重力バリア等）は再現していません
- スクショからの敵・ブロックの自動検出はなく、手で置く方式です
- ゲーム中に画面へ重ねて使うものではなく、スクショを使った事前確認用です
